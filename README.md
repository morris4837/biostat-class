# 生物統計學 (Biostatistics) 課程資料庫

本儲存庫收錄生物統計學課堂學習資料、SPSS / Excel 實作數據集、無母數統計檢定範例與各次回合作業檔案。

---

## 📁 檔案結構說明

### 📊 統計資料集 (Data Files)
| 檔案名稱 | 說明 / 統計主題 |
| :--- | :--- |
| `DM.xls` | 糖尿病 (Diabetes Mellitus) 臨床特徵與檢驗指標資料集 |
| `KW_Blood type.xlsx` | 血型分組與相關變數之 Kruskal-Wallis 無母數分析數據 |
| `KW_Pro_salary.xlsx` | 職業薪資與專業分組之 Kruskal-Wallis 統計檢定數據 |
| `Mann whitney.xlsx` | 兩組獨立樣本 Mann-Whitney U 檢定資料 |
| `OR_RR_吸菸與肺癌_SPSS教學資料_2026.10.22.xlsx` | 流行病學危險度分析（勝算比 Odds Ratio, 相對危險度 Relative Risk） |
| `SPSS 問卷作業 survey.xls` | 問卷調查問卷變數與編碼實作資料 |
| `Survival test example.xlsx` | 存活分析 (Survival Analysis / Kaplan-Meier) 範例數據 |
| `smoking depression.xlsx` | 吸菸行為與憂鬱程度相關性分析資料 |
| `籃球投籃比賽.xlsx` | 投籃競賽各組別命中率與表現數據 |
| `調查情報20260331.xlsx` | 綜合調查統計原始資料 |
